Unary minus is not supported for variables, although known literal values can be negative. To negate a variable, subtract it from zero. 

-2 = r // ok
a + -2 = r // ok

-x = r // error
0 - x = r // ok

a + -x = r // error
a + 0 - x = r // ok

Logical negation !varName is translated directly into 3CNF-SAT format as the literal !varName without introducing any extra variables or equations. This operation is completely free in terms of both memory consumption and execution time. In the case of !a == r, a link {a: !r} is created.

Operation Name Example Details
! logical not !a == r Free operation (only link)
~ bitwise not ~a = r Free operation (only links); ~5 = -6
%% floor %%a = r Free operation (only links); %%5.75 = 5
{~} modular bitwise not {~}a = r Free operation (only links); {~}5 = 250 (size 8 0)
^: isolate the highest set bit ^:a = r With size 15 0: 90 clauses (6 clauses per bit); ^:6 = 4
|: mask from the highest set bit |:a = r With size 15 0: 45 clauses (3 clauses per bit); |:6 = 7
+: population count +:a = r With size 15 0: 134 clauses (approx. 10 clauses per bit); +:6 = 2
<:> reverse bits <:>a = r Free operation (only links); <:>2 = 64 (size 7 0)
{<:>} modular reverse bits {<:>}a = r Free operation (only links); {<:>}2 = 32 (size 7 0)

Common Bitwise & Arithmetic Patterns

Set variable as an integer: 

%%a = a // a is an integer

size 8 3;

Set consecutive bits to zeros then ones: 

|:a = a
+:a = bitsNumber

size 8 0;

Isolate the highest set bit manually: 

~( (|:a) >> 1) = t

a & t = r

size 8 0

Integer Binary Logarithm: If all numbers are integers, use this pattern to find the floor binary logarithm for a positive number: 

a >= 0

|: a = t

+: (t >> 1) = floorIntLog

size 8 0

Upper Limit on Multiplication: Instead of performing expensive multiplication, you can obtain the index positions of each number's highest set bit and add those indices together: 

// a * b less than 8 bit number

aLog + bLog < 8

a >= 0; b >= 0;

+: (|: a) = aLog;
+: (|: b) = bLog;
