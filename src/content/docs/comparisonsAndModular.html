Comparison

Comparison (less than, greater than) is performed by subtraction. Setting a sign constraint such as a >= 0 or a < 0 is free. If a variable is positive and its value is compared against an exact power-of-two upper bound, certain optimizations apply and the comparison can also be free (for example, a >= 0; a < 64;).

Equal and Unequal

The equation a = b == r is equivalent to a != b == !r. A single equality sign (= or ==) acts as the equation separator; if multiple signs are present, one serves as the separator while the others function as operators.

  • a = b == true creates a variable link {b:a} (free).
  • a = b == r costs 7 clauses per bit (if r == true then a = b; if r == false then a != b).
  • a = b == false costs 7 clauses per bit.

In many cases, it is better to use a conditional construct instead: r ? a = b costs only 2 clauses per bit (if r == true then a = b; if r == false then a and b can have any value, including a = b).

Logical Imply and Boolean Condition

Similarly, for boolean values, using a boolean condition construct is often more efficient than a logical implication operator:

  • a ? b == r — 2 clauses: if a is true then b equals r (this is a construct, not an operator).
  • !a || b == r — 3 clauses: if a is true then b equals r; if a is false then r equals true.

Power-of-Two Modular Operations: {operator}

In modular expressions a {operator} b = r, operands a, b, and r must be positive integers with a fractional part of zero. Only the integer part is used, and all operations are performed modulo a power of two. Any negative input or number with a non-zero fractional part returns false. 

x {+} -1 = 2; // result is false

x {*} 0.5 = 1; // result is false

Difference Between {<<} and <<

The modular shift {<<} operates strictly on the integer part (ignoring the sign bit) and behaves like a standard left shift in most programming languages. In contrast, << operates as arithmetic multiplication by a power of two without overflow, preserving the number's sign (positive remains positive, negative remains negative).

Shift Example: Subtracting one from an odd number is free using shifts: 

// if x is odd, y = x - 1
(x >> 1) << 1 = y

Exponentiation

It is often preferable to set an upper bound as a power of two. The exponentiation operator ** can be used for this purpose when both operands are known values. If the first operand is a variable, only the second power (squaring) is supported. 

r < 2 ** 5
a ** 2 = r
