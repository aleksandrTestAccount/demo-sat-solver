Division

Avoid division if possible. Division is replaced by multiplication and addition, meaning the equation a / b = r introduces the following constraints:

  1. b * r + remainder = a
  2. remainder >= 0
  3. b * oneBitNumber > remainder

In a / b = r, b cannot be zero because no solution exists that satisfies both remainder >= 0 and b * oneBitNumber > remainder.

Remainder and Division with Remainder

Division and division with remainder return different quotients for numbers with a fractional part. The division with remainder construct uses the syntax a /% b = (quotient, remainder) and enforces the following relations: 

b * quotient + remainder = a
remainder >= 0
b * oneBitNumber > remainder
quotient = %%quotient // integer

Here, quotient is the integer result of dividing a by b, and remainder is the non-negative remainder (a mod b). Because calculating the remainder naturally computes the quotient as well, this construct returns both values as a pair.

Unlike the division with remainder construct, the remainder operator (a % b = r) can be used directly within an equation line. However, since quotient is still calculated internally, it can trigger an overflow error when working with fractional numbers: 

// result is false, even if 1 % 0.25 = 0, because 1 / 0.25 = 4 (overflow)

a % 0.25 = r

a >= 1
a <= 1

size 1 2 // max value is 1

Multiplication

Ordinary multiplication works only with positive numbers. When using a fractional part, the number of generated clauses increases significantly.

Multiplication of Negative Numbers: To multiply negative numbers manually, you must check their signs and compute their absolute values: 

// a * b = r 

a:s == b:s == !r:s // signs

0 - a = ta
0 - b = tb

!a:s ? a : ta = aAbs 
!b:s ? b : tb = bAbs

aAbs * bAbs = rAbs

0 - rAbs = tr

!r:s ? rAbs : tr = r

size 8 0

You can use the shorthand operator !* (a !* b = r), which automatically generates the sign-handling logic shown above. If one operand is guaranteed to be positive (for example, b), you can write a lighter version manually: 

// a * b = r 

a:s == r:s // signs

!a:s ? a : ta = aAbs 

aAbs * b = rAbs

0 - rAbs = tr

!r:s ? rAbs : tr = r

size 8 0

Multiplication by Boolean Value: The ?* operator multiplies a number by a boolean condition, expanding into conditional expressions: 

// Subset sum

2 ?* x1 + 3 ?* x2 + 8 ?* x3 + 7 ?* x4 + 9 ?* x5 = 19

size 5 0
