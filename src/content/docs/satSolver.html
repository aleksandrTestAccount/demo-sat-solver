The current implementation of the SAT solver is a baseline prototype and will be rewritten in future updates. Note one important behavior: if a variable has no effect on the final result (meaning it can be either true or false), the solver sets that variable to false by default.

config solve false

To inspect how many variables and clauses a model generates without running the solver, use config solve false. When enabled, the code is parsed, validated, compiled into clauses, and optimized, while the final solving step is skipped (note that memory overflow is still possible if an extremely large number of clauses is generated): 

size 101 0

a * b = 1267650600228229401496703205376

a < 2 ** 50

config solve false
