Proto Equation Language

A declarative constraint language that compiles arithmetic, bitwise, and logical equations into 3-CNF-SAT boolean formulas (at most 3 literals per clause) and solves them directly in the browser using MiniSat (WebAssembly) or a built-in JS solver.

01 Bit-Blasting Fixed-point 2's complement vectors
02 3-CNF Compilation Reduction to ≤3-literal clauses
03 3-SAT Solver MiniSat (WASM) or built-in JS backtracking solver

Quick Start: Enter your constraints in the editor (or click Copy To Editor → below) and press Solve. Define the global bit-width once for all rational numbers using size <int> <frac>. 

// Integer factorization compiled to 3-CNF-SAT
a * b = 247
a > 1
b > 1

// 8-bit integer, 0-bit fraction (+1 sign bit)
size 8 0
Design Philosophy

Loops and conditional statements are intentionally omitted—a preprocessor supporting directives like #for, #if, and #define is planned for future releases. Even then, this language serves strictly as a low-level logic core: for complex systems, you should generate .eproto code using your favorite programming language.

Educational Purpose

This project was created strictly for educational purposes. With its clean, intuitive syntax and step-by-step CNF inspection, it serves as an accessible introductory playground for students exploring SAT, SMT, bit-blasting, and NP-complete problems.


Compilation Trade-off: This tool attempts to build a 3-CNF formula with the smallest possible number of clauses. While this is not always achieved, keep in mind that a minimal clause count is not always good—it can be inconvenient for SAT solvers and slow down the search.

DIMACS Export & Import: Need more solving power right from the browser? Click To DIMACS next to the Solve button to export your compiled 3-CNF formula, run it in any external local or online SAT solver, and paste the raw output back to decode the final variable values and equations.

Node.js CLI & External DIMACS Solvers

Local Execution

For local automation, scripting, and heavier benchmarks, clone the repository and use the zero-dependency Node.js CLI runner (cli/index.js). By default, it executes equations using the bundled MiniSat (WebAssembly) solver without requiring any external binaries.

You can also pass the --solver flag to switch to the built-in JS solver or stream the compiled 3-CNF formula via standard DIMACS CNF into external industrial SAT/SMT solvers installed in your system PATH:

  • minisat — Bundled C++ MiniSat compiled to WebAssembly (default, works out of the box).
  • builtin — Built-in slow and simple JavaScript 3-SAT solver.
  • z3 — Microsoft Z3 SMT/SAT solver.
  • cadical — CaDiCaL CDCL SAT solver.
  • cryptominisat — CryptoMiniSat solver.
# 1. Clone the repository and enter the directory
git clone https://github.com/aleksandrtestaccount/demo-sat-solver
cd demo-sat-solver

# 2. Run with the bundled MiniSat WASM solver (default, no extra dependencies)
node cli/index.js examples/root.eproto

# 3. Or run with the built-in slow and simple JS solver
node cli/index.js examples/example.eproto --solver builtin

# 4. Optional: install external DIMACS solvers on Linux (Debian/Ubuntu)
sudo apt update && sudo apt install -y z3 cadical cryptominisat

# 5. Offload solving to external industrial DIMACS solvers
node cli/index.js examples/root.eproto --solver z3
node cli/index.js examples/root.eproto --solver cadical
node cli/index.js examples/root.eproto --solver cryptominisat
