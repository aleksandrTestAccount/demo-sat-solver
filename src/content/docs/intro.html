Proto Equation Language

A declarative constraint language and built-in solver that compiles arithmetic, bitwise, and logical equations into 3-CNF-SAT boolean formulas (at most 3 literals per clause) and solves them directly in the browser.

01 Bit-Blasting Fixed-point 2's complement vectors
02 3-CNF Compilation Reduction to ≤3-literal clauses
03 3-SAT Solver Basic backtracking search with unit propagation

Quick Start: Enter your constraints in the editor (or click Copy To Editor → below) and press Solve. Define the global bit-width once for all rational numbers using size <int> <frac>. 

// Integer factorization compiled to 3-CNF-SAT
a * b = 247
a > 1
b > 1

// 8-bit integer, 0-bit fraction (+1 sign bit)
size 8 0
Design Philosophy

Loops and conditional statements are intentionally omitted—a preprocessor supporting directives like #for, #if, and #define is planned for future releases. Even then, this language serves strictly as a low-level logic core: for complex systems, you should generate .eproto code using your favorite programming language.

Educational Purpose

This project was created strictly for educational purposes. With its clean, intuitive syntax and step-by-step CNF inspection, it serves as an accessible introductory playground for students exploring SAT, SMT, bit-blasting, and NP-complete problems.


Compilation Trade-off: This tool attempts to build a 3-CNF formula with the smallest possible number of clauses. While this is not always achieved, keep in mind that a minimal clause count is not always good—it can be inconvenient for SAT solvers and slow down the search.
