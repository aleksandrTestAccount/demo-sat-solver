The binarySearch directive finds the minimum or maximum valid value for a target variable within an inclusive range: 

binarySearch min|max variableName lowerBound upperBound

For example, searching the interval from 0 to 1000 to find the minimum possible value of x: 

binarySearch min x 0 1000;

A possible execution path proceeds as follows:

  1. Check the left interval [0, 499]: result is true, found x = 120.
  2. Check the left interval [0, 59]: result is false.
  3. Check the right interval [60, 119]: result is true, found x = 90.
  4. Check the left interval [60, 74]: result is false.
  5. Check the right interval [75, 89]: result is false; return the last valid result: x = 90.

Note: Strategy selection and customization are planned for future updates, as the current search strategy can be suboptimal for certain tasks.

Examples

// result: {x3: 8}

x1 * x2 > 15; 
x1 + x2 = x3; 

x1 >= 0; x2 >= 0; x3 >= 0; 

size 6; 

binarySearch min x3 0 30;

// result: {x3: 9}

x1 * x2 < 15; 
x1 + x2 = x3; 

x1 > 1; x2 > 1; x3 > 1; 

size 6;

binarySearch max x3 0 30

a + b = 30

a * b = v

size + 10 0

binarySearch max v 0 1000

Performance Note: Currently, the entire equation system is regenerated from scratch at each binary search step, which is computationally expensive. In future versions, the problem will be generated once and only the interval bounds will be updated at each step.
