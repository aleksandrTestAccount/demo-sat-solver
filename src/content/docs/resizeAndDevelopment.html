Resize

Note: The resize construct is unstable and may be changed or removed in future versions.

resize supports all power-of-two modular operations as well as the following non-modular operations: +, -, *, **, >, >=, <, and <=. It temporarily adjusts the active bit width for integer and fractional parts across all supported operations on that line, fixing any excess higher-order bits to false: 

size 10 0;

resize 8 0: a + b = r  /* addition with 8 bits

a:10 == false
b:10 == false
r:10 == false

a:9 == false
b:9 == false
r:9 == false
*/

resize also works seamlessly with power-of-two modular operations: 

size 15 3;

// 8 bits for modular operations (mod 256):
resize 8 0: a {+} b {*} c = r {:<<:} 2

Development

This solver is currently in the prototype stage and serves as a proof of concept. The primary goal was to build the tool quickly so that it runs directly in the browser and can be used locally without requiring a backend server.

Initially, the language was designed around a minimal set of operators while avoiding function-like constructs. That constraint led to several specialized operators and syntax constructs such as {:<<:}, |:, +:, and <:>, which may be redesigned in future iterations.
