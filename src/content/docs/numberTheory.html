Discrete Logarithm Problem and Binary Exponentiation

For larger tasks such as the Discrete Logarithm Problem, it is often best to generate the equation-language code programmatically in your preferred language and then pass it to the solver. 

// dlog:
// base ** x = needle (mod m)

m = 241 
base = 190 
needle = 132

x >= 0 
x < m - 1
