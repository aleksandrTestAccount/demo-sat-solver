When expressions like a = b == true occur, variable a becomes linked to variable b, replacing all occurrences of a with b within the list of equations. 

x1 + a = x2
a = b == true
x3 * b = x4

This system transforms into: 

x1 + b = x2
x3 * b = x4

Bit shift operators are free because they simply establish links between corresponding bits. For example, a << 2 = r sets up the links r:2 == a:0, r:3 == a:1, and so on. No new variables or equations are created—only references between existing bits are established.
