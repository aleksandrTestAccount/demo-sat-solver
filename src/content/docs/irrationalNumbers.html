The tool is designed specifically for discrete quantities represented by a fixed number of bits. Consequently, there is no direct support for irrational numbers. For example, the equation x * x = 2 has no solution regardless of the number of fractional bits, because the square root of 2 is irrational.

To obtain an approximate solution for such equations, introduce an additional tolerance parameter that allows minor deviations: 

x * x + a = 2

a >= 0
a <= 0.0125

size 2 10

All pre-computable operations should be performed prior to execution. If you need to use the square root of a known number or mathematical constants such as PI or E, substitute them with precomputed approximate values.
