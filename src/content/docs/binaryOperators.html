Division and multiplication are performed only with positive numbers.

Consider an example with size 15 0. Every number uses 16 bits (16 variables); thus, for a, b, and r, there are 48 variables in total. Arithmetic operations create additional variables: for example, addition introduces a carry variable and an intermediate result variable, adding 15 * 2 = 30 extra variables. Additionally, each bit in addition generates 10 clauses, except for the first bit and the last (sign) bit, which produce fewer clauses.

Approximate calculations for additional variables and clauses during addition:

  • Additional vars amount = 2 * bitSize - 2
  • Clauses = 10 * bitSize - 6
