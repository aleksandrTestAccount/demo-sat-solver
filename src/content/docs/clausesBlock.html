Every simple equation is transformed into 3CNF-SAT format. For example, a logical OR operation converts into three clauses: 

a || b == r /* transforms into:
    clauses {
        a b !r 
        !a r
        !b r
    }
*/
/* one of four possible results is {a:false, b:true, r:true}, every clause will be true:
    clauses {
        a b !r  --> false || true  || false == true
        !a r    --> true  || true           == true
        !b r    --> false || true           == true
    }
*/

The clauses block allows specifying lists of clauses directly, one clause per line. Each clause must contain one, two, or three literals, following 3CNF-SAT restrictions. 

a || b == r 

//additional clauses
clauses {
    a b r 
    a !b !r
    !a !b !r
}

/* Full list of clauses (3 from logic operation and 3 from clauses block):
    clauses {
        a b !r 
        !a r
        !b r
        a b r 
        a !b !r
        !a !b !r
    }
*/

/* the only possible result is {a:true, b:false, r:true}, every clause will be true:
    clauses {
        a b !r   --> true  || false || false == true
        !a r     --> false || true           == true
        !b r     --> true  || true           == true
        a b r    --> true  || false || true  == true
        a !b !r  --> true  || true  || false == true
        !a !b !r --> false || true  || false == true
    }
*/

Disjunction equations of up to three literals (such as a || b || c or a || b || c == true) convert directly into a single clause without introducing intermediate variables: 

a || !b || !c 

/* converts to
    clauses {
        a !b !c
    }
*/
